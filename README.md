# NetherGlide Minecraft Plugin

NetherGlide is a Minecraft Paper server plugin for focusing on Gilded Blackstone: it checks the block directly in a player’s line of sight and displays flame and glow particles when that block is targeted. It is a Java Minecraft server plugin, not a resource pack, and it does not highlight blocks through walls or include anti-cheat bypass features.

## Install

1. Build the project with Java 21 and Maven by running `mvn package` from the project directory.
2. Copy `target/plugin.jar` into your Paper server’s `plugins` directory.
3. Restart the server.

## Use

1. In game, run `/gildedblackstone` or `/gbfocus` to toggle the effect.
2. Look directly at Gilded Blackstone within 32 blocks to see the particles.
3. The effect requires the `gildedblackstone.use` permission, which defaults to enabled.
